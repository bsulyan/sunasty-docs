# Sunasty Client-Side Tooling & Libraries

Welcome to the official developer documentation for **Sunasty** libraries and utilities.

All libraries are designed with a single architectural principle: **100% client-side, zero-dependency, local execution**.

## Open-Source Libraries

- **[sunasty-color-math](https://github.com/bsulyan/sunasty-color-math)**: Zero-dependency sRGB, HSL, and OKLCH color conversions with WCAG 2.1 contrast calculations. Available on [npm](https://www.npmjs.com/package/sunasty-color-math), [pkg.go.dev](https://pkg.go.dev/github.com/bsulyan/sunasty-color-math-go), and [GitHub](https://github.com/bsulyan/sunasty-color-math).
- **[sunasty-qr-payload](https://github.com/bsulyan/sunasty-qr-payload)**: Parser for structured QR payloads (Wi-Fi, vCard, TOTP, Email, SMS) with Web Crypto RFC 6238 TOTP generator. Available on [npm](https://www.npmjs.com/package/sunasty-qr-payload).

## Web Applications

- **[Sunasty Color Picker & Palette Extractor](https://sunasty.com/color-picker/)**: Live eyedropper, OKLCH converter, and WCAG contrast checker.
- **[Sunasty QR Code Scanner](https://sunasty.com/qr-scan/)**: Multi-scale offline QR decoder.
- **[Sunasty Developer Suite](https://sunasty.com/dev/)**: In-browser tools for JSON, regex, hashing, and contrast testing.
- **[Ulysan](https://ulysan.fr/)**: Digital craftsmanship and software engineering studio.
